# SQL & Data Warehouse Directory

This directory is designated for Data Warehouse DDL scripts, ETL SQL procedures, and OLAP queries developed by **Member 2 — Data Warehouse & OLAP Engineer**.

## Expected Structure
- `01_schema_ddl.sql` - DDL scripts for Star Schema creation (`Fact_Sales`, `Dim_Customer`, `Dim_Product`, `Dim_Time`)
- `02_etl_transform.sql` - SQL ETL procedures to populate dimension and fact tables from raw staging data
- `03_olap_queries.sql` - Analytical SQL scripts for Roll-Up, Drill-Down, Slice, and Dice operations
